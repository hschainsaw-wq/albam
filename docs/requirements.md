# albam 要件定義書（v0.1）

Apple Music の好きなアルバムを、自分用にタグでカテゴライズして管理する Web アプリ。

## 1. 前提・方針

| 項目 | 決定事項 |
|---|---|
| 利用者 | 自分ひとり（ログイン機能なし） |
| 形態 | Web アプリ（PC / スマホのブラウザ両対応、レスポンシブ） |
| 公開先 | 無料の静的ホスティング（GitHub Pages を第一候補） |
| データ保存 | ブラウザ内（IndexedDB）＋ JSON エクスポート / インポート |
| 想定規模 | 100〜500 枚 |
| 技術 | React + TypeScript + Vite（サーバー不要の SPA） |

## 2. 機能要件

### 2.1 アルバム登録
- Apple Music のアルバム共有 URL を貼り付けて登録する。
  - 例: `https://music.apple.com/jp/album/<名前>/<albumId>`
  - 曲の URL（`?i=<trackId>` 付き）を貼った場合も、所属アルバムとして登録する。
- URL からアルバム ID と国コードを取り出し、iTunes Lookup API（無料・キー不要）でメタデータを取得する。
  - 取得項目: アルバム名、アーティスト名、ジャケット画像、発売日、ジャンル、曲数、収録曲一覧、Apple Music の URL
- 取得結果をプレビューし、タグ・評価・メモをその場で付けて保存できる。
- 同じアルバムの重複登録は防止し、既存アルバムの編集画面へ案内する。
- 登録したアルバムの削除。

### 2.2 タグ（カテゴライズ）
- 1 枚のアルバムに複数のタグを付与できる。
- タグの作成・名前変更・削除。
- タグの統合（タグ A を B にまとめると、A の付いたアルバムに B が付き、A は削除される）。
- タグのグループ分け（例: 「ジャンル」「気分」「シーン」）。グループに属さないタグも可。
- 各タグに付いているアルバムの枚数を表示する。

### 2.3 評価・メモ
- ★5 段階、0.5 刻み（0.5〜5.0）。未評価も可。
- 自由記述のメモ（感想など）。

### 2.4 一覧・検索・並び替え
- 表示はジャケットのグリッド表示とリスト表示をボタンで切り替える（選択状態は記憶する）。
- キーワード検索: アルバム名・アーティスト名・メモを対象にする。
- タグで絞り込む: 複数タグを選べて、AND（すべて含む）/ OR（どれか含む）を切り替えられる。
- 並び替え: 追加日・アルバム名・アーティスト名・発売日・評価（それぞれ昇順と降順）。

### 2.5 アルバム詳細
- ジャケット、基本情報、収録曲一覧、タグ、評価、メモを表示・編集する。
- 「Apple Music で開く」ボタン（スマホでは Music アプリが起動する）。

### 2.6 データ管理
- 全データ（アルバム・タグ・タググループ）を JSON ファイルとして書き出す。
- JSON を読み込んで復元する（全置換 or マージを選べる）。
- データの保存先がこのブラウザだけで、ブラウザのデータを消すと失われることを設定画面に明記する。

## 3. 非機能要件
- 500 枚登録しても一覧の表示や絞り込みがすぐ終わる（目安 100ms 以内）。
- スマホ幅（375px）でも横スクロールなしで使える。
- ライト / ダークモードに対応（OS の設定に従う）。
- 一度読み込んだ後はオフラインでも閲覧できる（PWA 化は将来の対応）。

## 4. データモデル（案）

```ts
type Album = {
  id: string;            // Apple Music の collectionId
  title: string;
  artist: string;
  artworkUrl: string;
  releaseDate?: string;
  genre?: string;
  trackCount?: number;
  tracks?: { no: number; title: string; durationMs?: number }[];
  appleMusicUrl: string;
  country: string;       // 例: "jp"
  tagIds: string[];
  rating?: number;       // 0.5〜5.0（0.5 刻み）
  memo?: string;
  addedAt: string;       // ISO8601
  updatedAt: string;
};

type Tag      = { id: string; name: string; groupId?: string };
type TagGroup = { id: string; name: string; order: number };
```

## 5. 範囲外（v1 では対応しない）
- Apple Music ライブラリとの自動同期（MusicKit / Apple Developer Program が必要）
- 複数の端末間でのデータ同期、ログイン
- 一覧の公開・共有
- タグの色分け

## 6. 技術的なリスクと確認事項
- iTunes Lookup API をブラウザから直接呼べるか（CORS）: 呼べない場合は JSONP（`callback` パラメータ）で回避する。
- iTunes API は 1 分あたり約 20 リクエストの制限がある: 1 件ずつ登録する運用なら問題ない。
- Apple Music にしかなく iTunes API に出てこない作品がある: 取得に失敗したら手入力で登録できる経路を用意する。

## 7. 画面構成（案）
1. 一覧画面（メイン）: 検索バー、タグ絞り込み（AND/OR）、並び替え、グリッドとリストの切り替え、「＋追加」ボタン
2. 追加ダイアログ: URL 入力 → プレビュー → タグ・評価・メモ → 保存
3. アルバム詳細 / 編集画面
4. タグ管理画面: グループ、タグの名前変更・削除・統合、枚数表示
5. 設定画面: JSON の書き出しと読み込み、データ保存についての注意書き
